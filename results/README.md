# Manuscript result tables

The CSV files in `paper_tables/` reproduce Tables 1–6 of the manuscript.

The `configs/` directory contains the final two-dimensional benchmark configuration files and the corresponding detailed comparison CSVs. Large raw trajectories, model checkpoints, and dense `.npz` solution arrays are intentionally omitted to keep the GitHub repository lightweight. They can be regenerated with the scripts in `experiments/two_dimensional_periodic/` and `experiments/two_dimensional_dirichlet/`.
